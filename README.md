# KruNote

KruNote คือ PWA ส่วนตัวสำหรับครูมัธยม ใช้เช็กชื่อ ติดตามการส่งงาน กรอกคะแนนรวม ตัดเกรด บันทึกพฤติกรรม และสร้างรายงาน PDF/Excel แยก ม.4–ม.6 และรายห้อง ข้อมูลหลักอยู่ใน Google Sheets ของครู ไฟล์รายงานอยู่ใน Google Drive

## ความสามารถ

- Quick Edit ทั้งห้อง: มา/สาย/ขาด/ลา, ส่งแล้ว/ส่งช้า/ยังไม่ส่ง/ยกเว้น และคะแนนรวม
- สร้างงานหรือข้อสอบหนึ่งครั้ง แล้วเลือกหลายห้องในระดับเดียวกันหรือต่างห้อง
- คิวตรวจงานและความคืบหน้ารายงาน
- ตารางคะแนนแบบถ่วงน้ำหนัก พร้อมเกณฑ์ 4–0 และล็อกผลเกรด
- บันทึกพฤติกรรมเชิงบวก/ควรติดตาม โดยไม่กระทบคะแนน
- ส่งออก PDF หรือ Excel หนึ่งห้อง หนึ่งระดับ หลายห้อง หรือทุกห้อง
- ทำงานออฟไลน์ด้วย cache และ outbox ที่เข้ารหัสบนอุปกรณ์
- ภาษาไทย/English, Light/Dark/System/High contrast และโหมดกระชับ
- ข้อมูลตัวอย่าง 90 คนใน 6 ห้อง เพื่อทดสอบโดยไม่ใช้ข้อมูลจริง

## เริ่มใช้งาน

1. เปิด Apps Script project ที่เชื่อมกับไฟล์นี้ แล้ว Deploy เป็น Web app โดยให้ execute as **Me** และ access เป็น **Anyone**
2. เปิด GitHub Pages ของ KruNote แล้ววาง URL ที่ลงท้าย `/exec`
3. เลือกว่าจะเพิ่มข้อมูลตัวอย่างหรือไม่ กดตรวจและเชื่อมต่อ
4. PIN ครั้งแรกคือ `1234` ระบบจะบังคับเปลี่ยนเป็นตัวเลข 6–12 หลักทันที
5. ทดสอบสร้างงาน เช็กชื่อ กรอกคะแนน และออก PDF/Excel ก่อนเพิ่มข้อมูลจริง

> Web app เปิดให้เรียก endpoint ได้เพื่อให้ GitHub Pages เชื่อมต่อ แต่ทุกการอ่าน/เขียนข้อมูลต้องผ่าน PIN session แบบหมดอายุ มี rate limit และข้อมูลออฟไลน์เข้ารหัสแล้ว ควรเก็บ Web App URL และ PIN เป็นส่วนตัว

## พัฒนาและตรวจสอบ

ต้องใช้ Node.js 22 ขึ้นไป

```bash
npm install
npm run verify
npm run dev
```

`npm run verify` รันทดสอบ domain logic, type check, production build และตรวจไฟล์ PWA ส่วน `.clasp.json` มี Script ID ส่วนตัวจึงถูก ignore และไม่ขึ้น Git

## โครงสร้างข้อมูล

Apps Script สร้าง Spreadsheet `KruNote Data` พร้อมชีตสำหรับปีการศึกษา ภาคเรียน ระดับ ห้อง นักเรียน ตารางสอน การเข้าเรียน งาน เป้าหมายห้อง การส่ง คะแนน พฤติกรรม เกณฑ์เกรด ผลเกรด งานส่งออก และ mutation log การเขียนทุกครั้งมี ID/version/timestamp และใช้ idempotency key ป้องกันการบันทึกซ้ำ

## การสำรองและความเป็นส่วนตัว

- สำรองได้โดยทำสำเนา Spreadsheet และโฟลเดอร์ `KruNote Reports` ใน Drive
- ใช้ข้อมูลจำลองในการสาธิตหรือทดสอบเสมอ
- อย่า commit `.clasp.json`, PIN, Web App URL หรือข้อมูลนักเรียนจริง
- หากอุปกรณ์สูญหาย ให้สร้าง deployment ใหม่และเปลี่ยน PIN
